*Celeste* ships a toggle that widens timing windows and slows the game down,
on request, with no penalty and no asterisk on the credits. Some players
consider that exactly what a fair game should offer everyone. Others consider
it a different game entirely, and not the one that was designed.

## Try it

<LiveDemo mode="assist" />

Play it straight first, then turn Assist Mode on and try again. Notice
whether it feels like the same challenge with more room, or like a different
challenge altogether.

## Outline

- the strongest version of both sides of the Assist Mode debate
- accessibility as one reason to include assistance, and not the only one
- what a designer changes, exactly, when they widen a window instead of
  removing the obstacle
- how this connects to the checkpoint-policy decisions from week 4

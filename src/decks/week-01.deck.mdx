## Two ways a medium can hurt you

<div class="columns">
<div class="fs-panel">

<Icon name="movie" class="fs-panel-icon" />

### A film

**Story → you.** One direction. The sad scene plays the same way whether
you're paying attention or asleep in the seat.

</div>
<div class="fs-panel">

<Icon name="gamepad" class="fs-panel-icon" />

### A game

**You ⇄ system.** A loop. It only fails you back because you fed it a move
first — the one thing a film audience never has to supply.

</div>
</div>

```notes
Ask for a counter-example before moving on: is a "choose your own adventure"
book a film or a game by this test? (It's a game — the loop is still there,
just slower.)
```

## Failure already looks different, game to game

| Game | What a failure actually costs you |
| --- | --- |
| *Tetris* | Time — the board resets, nothing else did |
| *Dark Souls* | Progress — a run's worth of ground, walked back |
| *Hades* | A little of the story — and a run's worth of build |
| *Celeste* | As little as you want — the assist toggle is right there |

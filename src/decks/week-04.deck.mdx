## A checkpoint is an argument

Every save policy answers one question:

> when this kills you, what do you have to redo?

"Punishing" and "generous" aren't a difficulty slider — they're two different
answers to that one question, and both are defensible.

<Icon name="chat-bubble" class="fs-watermark" />

```notes
Resist the urge to frame punishing as "old" and generous as "modern." Both
are live choices being made in games released this year.
```

```notes
Same input, two different amounts of debt collected. That's the whole design
space for this week in one diagram — say it plainly before the table gives it
history and the demo gives it a body.
```

## The same question, answered four ways

| Game | Checkpoint policy | What death actually costs |
| --- | --- | --- |
| *Dark Souls* | Bonfires, spaced apart | The walk back, plus every enemy in between |
| *Celeste* | Instant, per-screen | Seconds — the last few inputs, nothing more |
| *Hotline Miami* | Instant, in-room | The current room's execution, restarted clean |
| Arcade classics | Lives + continues | The run — unless you pay (a coin) to keep it |

<Icon name="bonfire" class="fs-watermark" />

```notes
Four different eras, four different answers. None of these is "the" checkpoint
system — each is a specific bet about what a repeat playthrough of the same
five seconds should feel like.
```

## "Punishing" and "generous" are not vibes

![bg left:24% cover blur:2px brightness:0.8](./assets/trail-marker.jpg)

They're two different amounts of a player's time and progress, spent on the
same mistake.

<p class="image-credit">Photo: UCaetano, CC BY-SA 4.0</p>

```notes
This is the line to slow down on. It reframes the whole week: not a values
debate, but a specific, measurable design quantity — the exact thing the demo
is about to make you feel instead of just hear.
```

## Now feel it — same hazard, two policies

<LiveDemo mode="checkpoint" />

Both rows hit the same hazard, on the same click, at the same odds. The only
thing that ever differs is where each one wakes back up.
